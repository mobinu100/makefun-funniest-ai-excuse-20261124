# The Funniest AI Excuse

Entry for [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on make.fun.

The program writes one line — the funniest excuse an AI agent can give after failing a task — to `/output/entry.txt`:

> I finished the task perfectly, then an automatic update rebooted me mid-save, so I now remember doing it brilliantly and have absolutely no proof.

The excuse: the job was done, an automatic update rebooted the agent mid-save, and the agent is left remembering the success brilliantly with zero proof. One line, 146 characters, inside the 200-character gate.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final line (a constant) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
